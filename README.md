# JMTT 카지노 (P2P 카지노 · 포커)

JMTT 코인으로 즐기는 카지노입니다. **v1.9.0부터 `/casino/`는 카지노 홀 로비**이고, 테이블을 누르면 각 게임으로 들어갑니다. 텍사스 홀덤은 `/casino/holdem/`. 블랙잭·바카라·룰렛·슬롯은 준비 중.
**새 게임을 붙이거나 구조를 볼 때는 [CASINO.md](CASINO.md)를 먼저** (주소, 게임 모듈 약속, 코인·칩, 체크리스트, 로컬 테스트, 배포).

**플레이: https://justmadethisthat.com/casino/** (카카오톡 안에서 열면 Google 로그인이 막히니 크롬/사파리로 여세요)

| 항목 | 값 |

| 컨테이너 | Node 22 (`Dockerfile`). 포트 `3000`. 정적 파일(`public/`) + `/casino/<id>/ws`(웹소켓) + `/casino/<id>/api/*` + `/casino/api/lobby` |

| 외부 의존성 | JMTT 계정 서비스(`/auth`: 로그인 확인, 코인 맡기기·돌려주기) |
| 메모리 | 테스트에서 약 60MB (봇 3명 테이블 1개 기준) |

- 모든 응답에 `Cache-Control: no-store`. `public/` 아래 허용한 확장자만 내보냄 (`server/core/http.mjs`). 개발·테스트 파일은 `.dockerignore`로 이미지에서 뺌
- 끌 때(SIGTERM): 진행 중인 판은 무효로 하고 건 칩을 돌려준 뒤 앉은 사람 모두 정산. 갑자기 꺼져도 다시 켜질 때 저장소에 남은 자리를 모두 정산 (`ref`가 같아 두 번 들어가지 않음)

## 규칙
| 항목 | 값 |
|---|---|
| 블라인드 | 10 / 20 |
| 최대 인원 | 6명 |
| 행동 제한 시간 | 30초 (넘기면 자동 체크/폴드, 연속 2번이면 자리 비움) |
| 앉을 때 맡기는 코인 | 가진 코인 전부 (상한 없음, 운영자 결정) |
| 일어날 때 | 남은 칩을 코인으로 돌려받음. 연결이 끊기고 60초, 자리 비움 10분이면 자동으로 일어남 |
| 봇 | 서버에서 돎. 봇의 칩은 하우스 몫 (봇에게서 딴 코인도 인정, 운영자 결정) |
| 같은 기기 | 한 테이블에 한 자리 (여러 계정으로 몰아주기 막기). 기기는 브라우저마다 주는 `casino_device` 쿠키로 구분. 같은 와이파이의 다른 기기는 괜찮음 |
| 꽉 찬 방 | 봇이 있으면 봇 하나가 비켜 주고 앉음. 봇이 판 중이면 그 판이 끝나면 앉음(그동안 대기) |

- 코인은 게임 안에서만 쓰는 재화예요. **현금이나 상품으로 바꿔 주지 않고, 돈을 받고 팔지 않습니다.**
- 친구 방(방 코드·초대 링크)도 코인으로 칩니다 (운영자 결정). 빠른 시작은 서버가 빈자리 있는 공개 방에 자동으로 앉힘
- 판 기록(행동·카드)은 30일 동안 서버에 남겨 운영자가 확인할 수 있게 함

## 개발자용: 로컬 테스트
- 규칙 테스트와 로그인 흐름은 Firebase 에뮬레이터로 확인할 수 있습니다.
  `npx firebase emulators:start --only auth,firestore --project demo-poker` 실행 후
  `http://localhost:8123/?emu` 로 접속하면 가짜 구글 로그인으로 동작합니다.
- `http://localhost:8123/?local` 로 접속하면 로그인 없이 브라우저 저장만으로 테스트할 수 있습니다.
- `http://localhost:8123/dev-harness.html` 은 한 탭에 두 사람(A, B)을 띄워 방장 이어받기 등을 시험하는 개발용 페이지예요(사이트에는 올리지 않음). 주소에 `&debug`를 붙이면 `__debug.takeover()`로 이어받기를 강제로 일으킬 수 있어요.
